# Core Java – Complete Practical Implementation

This repository contains a single Java program that demonstrates important Core Java concepts through practical implementation.

The objective is to revise Java fundamentals and understand how different concepts work together in a Java application.

## Topics Covered

### 1. Java Fundamentals
- Variables and Data Types
- Type Casting
- Operators
- Input and Output

### 2. Control Flow
- If-Else Statements
- Switch Statements
- For Loop
- While Loop

### 3. Data Handling
- Arrays
- Strings
- StringBuilder

### 4. Methods
- Method Declaration
- Method Calling
- Method Overloading

### 5. Object-Oriented Programming (OOP)
- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interfaces

### 6. Java Keywords
- this
- static
- final

### 7. Exception Handling
- try
- catch
- finally
- ArithmeticException
- IOException

### 8. Collections Framework
- ArrayList
- HashSet
- HashMap
- Iterator

### 9. Advanced Java Concepts
- Multithreading
- Lambda Expressions
- Stream API
- Optional Class

### 10. File Handling
- File Creation
- Writing Data into Files
- FileWriter

## How to Run

**Step 1: Compile the Java file**

```bash
javac CoreJavaComplete.java
```

**Step 2: Execute the program**

```bash
java CoreJavaComplete
```

## Technologies Used

- Language: Java

- IDE: VS Code / IntelliJ IDEA
