# Student Management System

A simple Java-based Student Management System built using JDBC and MySQL.

## Features
- Add Student
- View Students
- Delete Student

## Tech Stack
- Java
- JDBC
- MySQL
- Maven

## Concepts Covered
- Database Connectivity
- PreparedStatement
- CRUD Operations
- ResultSet
- Exception Handling

## How to Run
1. Clone the repository.
2. Configure MySQL database credentials in `DBConnection.java`.
3. Create the `college` database and `learner` table.
4. Update Maven dependencies.
5. Run `Main.java`.

## Purpose
Built to practice JDBC concepts and understand Java database connectivity through a hands-on project.
