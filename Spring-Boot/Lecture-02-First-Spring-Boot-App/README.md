# Lecture 02 – First Spring Boot Application & REST API

This is a complete minimal Spring Boot project.

## Run

```bash
mvn spring-boot:run
```

Then open:
- `http://localhost:8080/hello`
- `http://localhost:8080/api/student`

## Test with curl

```bash
curl http://localhost:8080/hello
curl http://localhost:8080/api/student
```
