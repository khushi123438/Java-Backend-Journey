# Lecture 01 – Spring Framework & Spring Boot Introduction

## Spring Framework
A Java framework that provides infrastructure for building applications. Important features include IoC, Dependency Injection, transaction management and integration support.

## Spring Boot
Built on top of Spring. It reduces setup through auto-configuration, starter dependencies and embedded servers.

## Spring vs Spring Boot

| Spring Framework | Spring Boot |
|---|---|
| More configuration may be required | Convention and auto-configuration reduce setup |
| Server setup is often separate | Embedded server is commonly provided |
| Dependencies are selected individually | Starter dependencies simplify dependency setup |
